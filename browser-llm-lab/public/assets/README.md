# Cypher horizon artwork

`cypher-horizon.png` is the original background artwork used by the Cypher
workspace hero and the sidebar landscape. It was generated for this project
with the built-in `image_gen` tool, guided by the user's reference image.
The interface itself is HTML, CSS, SVG, and JavaScript.

- File: `public/assets/cypher-horizon.png`
- Dimensions: 1942 × 809 pixels
- Format: opaque RGB PNG
- File size: 1,869,290 bytes
- Method: built-in image generation, not the CLI/API fallback

The production server serves the image through an explicit static route. This
documentation file is not in the server's public route allowlist.

## Final generation prompt

```text
Use case: stylized-concept.
Asset type: a cinematic website hero background image, artwork only, not a screenshot or finished user interface.
Create an original photorealistic science-fiction alpine landscape at night: an angular dark mountain ridge stretching across the lower third, a still midnight-blue lake along the bottom with a very subtle cyan reflection, and an immense richly detailed blue planet rising in the upper-right quadrant behind the mountains. The planet has realistic atmospheric scattering and a fine electric-cyan illuminated crescent on its upper-left rim. The mountain rock has restrained cool-blue edge light and convincing fine texture. A few tiny stars in a deep almost-black navy sky.
Composition: ultra-wide panoramic, approximately 2.4:1 aspect ratio, ideally 2400 by 1000. Keep the entire left half and the upper center mostly dark, uncluttered sky with generous usable negative space for a website headline. Place the mountain peaks lower than the horizontal centerline. The planet is an imposing focal point on the right, not centered, and must remain separated from the canvas edge. Fill the frame with landscape, no surrounding border. Refined premium technology visual, believable natural surface detail, cinematic contrast, moody, elegant and restrained.
Palette: near-black #030b12, deep midnight navy, muted icy blue, sparse luminous cyan. Most of the image should remain dark enough for white foreground typography.
Constraints: no text, no letters, no logos, no icons, no interface elements, no browser frame, no cards, no panther, no animals, no people, no spaceships, no neon grids, no excessive stars, no watermarks. Opaque background.
```
