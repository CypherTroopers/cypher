    What participation uses

    Up to 20 direct browser neighbors and 20 Common WSS connections per device; the whole network can contain more participants. This browser shares a total limit of 40 circuits across all Common connections and browser peers, including opening circuits. Up to 512 KiB of temporary queues, a 4 MiB application memory budget, and 100 MiB of application messages per ON session. Normal JSON payload limits: send 48 KiB/s, receive 64 KiB/s. Generation lowers these to 24 / 32 KiB/s and one endpoint circuit. Loading and benchmarking close circuits and pause stream forwarding. No WebGPU required.

    Each end uses WSS to reach an operator-configured Common. A separate WSS connection introduces browser peers. An ordered, reliable WebRTC DataChannel carries the encrypted bytes between browsers. Direct and TURN paths are measured and labeled. There is no gateway-only fallback for this mesh.

    Joining shares your approximate country with assigned peers, if available. Direct WebRTC connections may reveal connection IP addresses to peers. Node OFF closes the connections and clears the temporary stream buffers. Returning to this page does not restart participation.

    Common mesh relay · native endpoints authenticate and encrypt the RLPx stream. Browsers are relay hops, not native peers. This browser does not vote, mine, earn rewards or establish finality. Participating Common miners remain eligible. Map: Natural Earth, public domain.

    Memory on this device

    Chat and Research save messages here while memory is on. Matching user messages and notes help future answers. Turning memory off stops saving and recall; existing items stay until you delete them. Gateway conversations are separate.
