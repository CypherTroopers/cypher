# Country display anchors

`geo.mjs` maps a trusted Cloudflare country code to one shared country or territory point. It contains 249 entries. These points are visual anchors, not a person's position, a city estimate, or a claim that a country has a precisely calculated geometric centroid. The gateway does no IP lookup and makes no external geolocation request. It never sends an IP address to the browser for this feature.

The main table is adapted from [Google's DSPL countries.csv](https://developers.google.com/public-data/docs/canonical/countries_csv?hl=en), under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Seven entries missing coordinates in that table are taken from `LABEL_Y` / `LABEL_X` in [Natural Earth v5.1.2 10m Admin 0 Countries](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_admin_0_countries.geojson), which is [public domain](https://www.naturalearthdata.com/about/terms-of-use/). Those entries are AX, BL, CW, MF, SS, SX, and UM. Coordinates are rounded to two decimal places; this does not increase the provider's country-level accuracy.

`geo-data-sources.json` records retrieval time, exact downloaded-byte hashes, licenses, selected fields, and modifications. The obsolete AN entry and non-ISO GZ entry from the Google table are omitted. The selected source tables do not provide a BQ row, so BQ remains unplaced. No position is invented for missing coordinates. Unknown XX, Tor T1, missing headers, and malformed codes also remain unplaced. XK is retained as supplied by Google's table; displaying a provider country code is not a statement about political recognition.

To refresh the data, download the named primary sources and record their new hashes before editing the static table. Extract the Google rows with numeric latitude and longitude, omit AN/GZ, and overlay only the seven named Natural Earth rows with exact, unique `ISO_A2_EH` matches. Round to two decimals. Do not automatically merge all Natural Earth features: several dependencies share a parent code, which can move a country's marker to a remote island. New codes require a documented source row, not a neighboring country or capital guessed from a name. Preserve explicit null behavior and run `node --test tests/relay-geo.test.mjs tests/relay-gateway.test.mjs`.

Cloudflare's [IP geolocation setting](https://developers.cloudflare.com/network/ip-geolocation/) controls the country metadata supplied to the origin. Nginx must trust only Cloudflare's configured address ranges and overwrite client-supplied `X-Relay-Country`. `CF-IPCountry` is a request header sent to the origin; its absence from a site's response headers does not establish whether metadata was available. A screenshot showing “unknown” cannot identify a historical user's location or prove which part of that chain was missing.
